التخزين المحلي + نشر products.json لكل الأجهزة

تنبيه أمني: لوحة الإدارة الحالية تعمل كواجهة ثابتة على المتصفح وليست نظام مصادقة خادمي. لا تستخدمها على جهاز عام أو مشترك. غيّر كلمة المرور الافتراضية من الكود إن أمكن، ولا تشارك التوكن أو بيانات الدخول.
كيف يظهر التعديل على كل الأجهزة (كمبيوتر وهاتف)؟
1) عدّل المنتجات ثم اضغط نشر للمتجر
2) لو فعّلت «النشر التلقائي على GitHub» أدناه: ينشر فوراً بدون أي خطوة يدوية
3) بدون ذلك: يُنزَّل products.json — ارفعه إلى مستودع GitHub (استبدل القديم) ثم Commit
4) صفحة المتجر (index.html) تجلب products.json تلقائياً من الإنترنت عند فتحها وكل بضع دقائق، فيظهر التحديث على الهاتف بدون أي إجراء إضافي

النشر التلقائي على GitHub (اختياري)

فعّلها مرة واحدة ليصبح زر «نشر للمتجر» ينشر products.json مباشرة إلى مستودع GitHub بدون رفع يدوي. يلزم Personal Access Token (Fine-grained) بصلاحية Contents: Read & Write على هذا المستودع فقط. التوكن سيُحفظ محلياً في متصفح هذا الجهاز حتى لا يُطلب منك مرة أخرى. لا تستخدم هذه اللوحة على جهاز عام أو مشترك، لأن أي شخص لديه وصول إلى المتصفح قد يتمكن من استخدام التوكن المحفوظ.
